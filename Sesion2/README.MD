# Sesión 2: GitHub - Alta y Creación de Repositorio

## Objetivo
Registrarse en GitHub y crear un repositorio para las entregas del curso.

## Instrucciones

### 1. Darse de Alta en GitHub
1. Ve a [github.com](https://github.com)
2. Haz clic en "Sign up" (Registrarse)
3. Completa el formulario con:
   - Correo electrónico
   - Contraseña
   - Nombre de usuario
4. Verifica tu correo electrónico
5. Completa tu perfil

### 2. Crear el Repositorio del Curso
1. Una vez registrado e iniciada sesión en GitHub
2. Haz clic en el icono **+** en la esquina superior derecha
3. Selecciona **New repository** (Nuevo repositorio)
4. Completa los datos del repositorio:
   - **Repository name**: `ED-APELLIDONOMBRE`
   - Ejemplo: `ED-LucioGonzalo`
5. Agrega una descripción (opcional)
6. Selecciona **Public** para que sea visible
7. Opcionalmente, selecciona "Add a README file"
8. Haz clic en **Create repository**

## Formato del Nombre del Repositorio
- **Prefijo**: `ED-`
- **APELLIDO**: Tu apellido (sin espacios)
- **NOMBRE**: Tu nombre (sin espacios)
- Ejemplo: `ED-GonzaloLucio`, `ED-PérezJuan`, `ED-RodríguezMaría`

## Próximos Pasos
Una vez creado el repositorio, estarás listo para comenzar a hacer entregas del curso.
